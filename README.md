# 📊 Relatório Gerencial de Vendas — Power BI

Projeto desenvolvido como parte da Formação Power BI Analyst da DIO, utilizando a base Financial Sample disponibilizada pela Microsoft.

O objetivo foi construir um relatório mais elaborado no Power BI Desktop, utilizando recursos de navegação, filtros, indicadores e diferentes formas de visualização.

## 🎯 Recursos utilizados

- Power BI Desktop
- Power Query
- Segmentadores de dados
- Cartões de indicadores
- Gráficos de barras, colunas, linhas e gráfico combinado
- Indicadores / Bookmarks
- Navegador de indicadores
- Botões de navegação entre páginas

## 📄 Página 1 — Visão Geral

A primeira página apresenta os principais indicadores comerciais:

- Total de vendas
- Unidades vendidas
- Descontos
- COGS
- Filtros por ano e segmento
- Vendas por mês
- Vendas por país

Também foi implementada a troca entre diferentes visuais utilizando indicadores e navegador de indicadores.

![Página 1 - Visão Geral](pagina-1-visao-geral.png)

## 📈 Página 2 — Análise

A segunda página apresenta análises mais detalhadas:

- Lucro por segmento
- Vendas por produto
- Lucro por país
- Comparação entre vendas e lucro por mês
- Segmentação por ano e segmento

![Página 2 - Análise](pagina-2-analise.png)
